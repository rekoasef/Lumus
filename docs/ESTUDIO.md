# LUMUS — Módulo: Estudio & Aprendizaje

## Objetivo
Centralizar el aprendizaje y crecimiento personal y profesional.

## Ruta
`/estudio`

## Color del módulo
Cyan — `#06b6d4`

## Funcionalidades

### Temas / Cursos
- CRUD de temas de estudio con categoría (programación, idiomas, finanzas, etc.)
- Estado: pendiente, en_progreso, completado
- Progreso: 0-100%
- URL de fuente (link al curso, libro, recurso)

### Notas
- Notas asociadas a cada tema
- Editor de texto con soporte para código
- Tags para organizar
- Búsqueda global de notas

### Roadmap
- Vista visual del camino de aprendizaje
- Ordenar temas por prioridad

## IA — Lumus en Estudio

### Rol: Tutor personalizado

### Sugerencias rápidas
- "Explicame [concepto]"
- "Generame ejercicios sobre [tema]"
- "¿Cómo sigo aprendiendo [tecnología]?"
- "Armame un plan de estudio de 30 días para [tema]"

## Tablas de DB
`study_topics`, `study_notes`
